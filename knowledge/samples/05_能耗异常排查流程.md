# 能耗异常排查流程

> ⚠️ **本文件为原型测试用「模拟手册」，不是瀚川工业园已确认的真实操作手册。**
> 文中步骤顺序与判断标准均为演示用途。

## 1 异常分类

排查前必须先判断异常属于哪一类，因为四类的处理方法完全不同。

| 类别 | 表现 | 首要责任人 | 处理方向 |
|---|---|---|---|
| 数据质量异常 | 缺数、连续平值、负值、表底回退、超量程 | 计量数据工程师 | 修复数据链路 |
| 计量异常 | 倍率错误、单位错、接线错、CT 饱和、三相不平衡 | 计量数据工程师 | 核对台账与现场 |
| 能耗异常 | 突增、突降、夜间基载抬升、非工作时段运行 | 能源经理 / 节能专员 | 核查运行与工艺 |
| 归属异常 | 串户、共用回路未拆、租户边界错 | 租户运营代表 | 核对合同与接线 |

**最常见的管理失误是把"计量异常"当"能耗异常"去查**，于是花三天查设备，最后发现是倍率录错了。

## 2 排查总流程

```
异常告警
  → ① 检查数据完整性（有没有缺数、回退、时点错位）
  → ② 检查计量配置（倍率、单位、版本、生效时间）
  → ③ 检查归属关系（父节点、分摊、是否串表）
  → ④ 检查总分平衡（差异率与差异方向）
  → ⑤ 检查运行侧因素（检修、试机、临时用电、天气、产量）
  → ⑥ 形成结论或转人工现场核实
```

**这个顺序不能颠倒**：先排除"数不准"，再讨论"用得多"。

## 3 各步骤要点

### 3.1 检查数据完整性

- 15 分钟粒度下，一天应有 96 个点，缺 1~2 个点属于通讯抖动，缺 4 个点以上需要关注
- 连续多个点数值完全相同（平值），通常是通讯中断后主站补的假数据
- 表底回退需要确认是否换表或清零

### 3.2 检查计量配置

- 该表当前倍率与铭牌是否一致
- 是否存在多条时间重叠的配置版本
- 倍率变更前后电量是否出现与倍率变化倍数一致的跳变

### 3.3 检查归属关系

- 该表挂在哪个父表下，是否挂错
- 是否存在共用回路未拆分
- 同一回路是否被两块表同时计量

### 3.4 检查总分平衡

- 差异方向：正差异（总>分）多为漏计量，负差异（分>总）多为分表计量偏大
- 差异规模：与哪块表的电量规模相当，就先查哪块表
- 差异时段：是否与某块表的数据突变时刻吻合

### 3.5 检查运行侧因素

- 是否有计划检修、设备试机、临时施工用电
- 空调负荷是否随天气明显变化
- 产量是否有波动（生产能耗应与产量同向变化）

## 4 如何判断"能耗异常是否由计量错误引起"

这是最常被问到的问题，给出可操作的判断顺序：

1. **看跳变形态**：计量错误通常表现为**阶跃式整体跳变**，且跳变前后电量比值非常稳定，恰好等于倍率比值；真实负荷变化通常有渐变过程，且与生产/天气/时间规律吻合。
2. **看波及范围**：倍率错误只影响单块表；真实负荷变化往往影响同一回路下的多块表。
3. **看平衡差**：计量错误会在总表与分表之间制造出与错误量级相当的差异；真实负荷变化不会改变平衡关系（总表也会同步变化）。
4. **看工单**：有无对应的换表、增容、改造工单。有工单且时间吻合 → 合法变更；无工单 → 高度怀疑配置错误。
5. **看历史相似案例**：同类表、同类回路以往是否发生过同类问题。

## 5 常见异常的快速判断表

| 现象 | 优先怀疑 | 第一动作 |
|---|---|---|
| 单表电量在某时刻起放大 10 倍且稳定 | 倍率录入错误 | 核对铭牌与配置历史 |
| 单表电量归零或极小 | 表计故障 / CT 开路 / 通讯中断 | 查采集状态与现场 |
| 总表远大于分表合计 | 漏装表 / 私接 / 分表缺数 | 先查分表完整性，再查接线 |
| 分表合计大于总表 | 分表倍率偏高 / 重复计量 | 逐表核对倍率，查是否串表 |
| 夜间基载突然抬升 | 设备未停机 / 新增常运行负荷 | 查运行记录与新增设备 |
| 周末负荷与工作日无差异 | 归属错误或计量点接错 | 核对回路与归属 |
| 三相电流差异大 | 三相不平衡 / 单相负荷集中 | 现场测量（需安全评估） |

## 6 处置与闭环

1. 确认原因后，明确责任方与整改措施
2. 涉及计量数据的更正，必须走变更流程并说明影响范围
3. 涉及运行的调整，由能源经理协调
4. 处置完成后回填结论，关闭异常单
5. 有代表性的案例沉淀进知识库，供后续参考

## 7 排查禁忌

1. 不要在未确认原因前调整计量数据
2. 不要用"经验估算"替代实际核查后就直接改数
3. 不要跳过数据完整性检查直接查设备
4. 不要仅凭一次异常就修改阈值（可能是真实异常被淹没了）
