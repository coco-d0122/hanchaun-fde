# 量化测试计划

> 版本：V1.0（2026-11-06）；项目：瀚川工业园能耗监测与异常定位智能体系统；阶段：TEST。
> 原则：**复用现有 tests/（pytest 分层）、scripts/ 自测脚本、eval/ 评测体系，不重新开发测试框架**；全部结果来自真实执行，证据文件存于 `Test/evidence/`。

## 1. 测试对象与环境

| 项 | 值 |
|---|---|
| 被测系统 | hanchaun-fde MVP（main 分支，本地运行） |
| 运行环境 | Windows + Python venv；SQLite(WAL)；LLM=mock 离线口径 |
| 访问地址（本次实测） | http://127.0.0.1:8766/（本地）；**无公网部署**，Docker 配置齐备但宿主机守护进程不可用 |
| 测试框架 | pytest（分层：unit/integration/agent/evaluation）+ 项目自测脚本（confirmation_selftest 等） |

## 2. 测试范围与量化指标

| 类别 | 对应交付报告 | 覆盖来源 | 量化通过标准 |
|---|---|---|---|
| 正常流程 | 正常流程测试报告 | integration/chat_agent+report_export、unit/rag_evidence、评测 30 条 | 核心链路用例 100% 通过；评测 30/30 |
| 边界情况 | 边界情况测试报告 | unit/phase11_gaps（预算/幂等/scope）、unit/context（多轮歧义） | 边界用例 100% 通过；超限行为符合设计 |
| 对抗性 | 对抗性测试报告 | agent 自测套件（五道闸/防循环）、confirmation_selftest 19 项 | 闸触发 100% 拦截；确认机制防绕过 100% |
| 权限安全 | 权限安全测试报告 | integration/auth_rbac、unit/security、unit/ratelimit | 未登录/越权/CSRF 缺失 100% 拦截 |
| 故障恢复 | 故障恢复测试报告 | backup_restore_drill、Agent 停用开关、LLM 降级 | 恢复行数一致；停用后人工功能保留 |

## 3. 测试方法

1. **自动化回归**：`pytest -q` 分组执行，输出保存为证据（Test/evidence/*.txt）；
2. **专项自测**：项目脚本 `scripts/confirmation_selftest.py`（19 项）、评测执行器（RUN_AGENT_EVAL=1）；
3. **端到端冒烟**：真实启动 uvicorn，curl 走登录→知识库→异常→Agent SSE→复核→指标八项，真实响应保存为 `evidence/mvp_smoke.txt`；
4. **恢复演练**：`scripts/backup_restore_drill.py`（备份→校验→删表→恢复→行数比对）。

## 4. 证据与截图约定

本执行环境无浏览器截屏工具，**不伪造截图**。所有报告以以下真实证据替代：
- pytest 逐用例通过输出（evidence/*_pytest.txt）；
- 自测脚本逐项 PASS 输出（evidence/confirmation_selftest.txt）；
- 冒烟测试真实 HTTP 请求与响应（evidence/mvp_smoke.txt）；
- 恢复演练报告（evidence/backup_drill.txt、eval/restore_drill_report.json）。
教师可在本机复跑命令复核（命令均写入各报告）。

## 5. 通过判定与遗留

- 全部量化标准满足即判"通过"；已知残留（1 skipped/1 xfail、真实 LLM 基线待做）如实标注不隐瞒。
- 遗留：Docker 公网部署验证、真实 LLM 下评测与压测基线——不阻塞 TEST 结论，已写入《完成情况》。
