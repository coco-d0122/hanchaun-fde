# 文档索引

本目录存放两类材料：

- `phases/`：各阶段的设计与验收记录（按时间顺序，保留当时的取舍与已知问题）
- `acceptance/`：上线前检查与验收类文档（阶段9 起）

常读的四份工程文档在根目录：

| 文档 | 内容 |
|---|---|
| [architecture.md](architecture.md) | 已实现的架构：双通道、Harness 循环、领域层划分、数据模型、关键取舍、未实现清单 |
| [api.md](api.md) | 全部 HTTP 接口、SSE 事件契约、错误结构与限流响应 |
| [deployment.md](deployment.md) | 本地启动、环境变量、Docker、反向代理、备份恢复、升级回滚、常见问题 |
| [security.md](security.md) | 威胁模型、四层 Agent 约束、内容安全、已实现/未实现边界、事故响应 |
