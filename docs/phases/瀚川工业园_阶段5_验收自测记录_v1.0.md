## 三、已知偏差与说明（需业务方知悉）

1. **LLM 为离线模拟**：未配置 `LLM_API_KEY`，回答为模板文本。因此"提示词改动导致**行为**变化"只能从消息的 `prompt_version_id` 与硬约束段验证，真实语义变化需接入模型后复测。
2. **复核记录表恒为空**：`review_records` 表与只读接口已就绪，写入接口按方案 7.2 **有意不注册**（`anomaly:review:submit` 不授予任何角色，含 admin）。
3. **管理页路由与方案命名差异**：知识库页落地为 `/admin/kb`（方案写作 `/admin/knowledge`），提示词接口带 `{code}` 段以同时支持 `qa` / `anomaly`；语义与权限不变。
4. **`/admin/anomalies` 的页面闸门**：要求 `anomaly:read` + `audit:conversation:read`。原因是 `anomaly:read` 普通用户也有（聊天页需看事件），而本页是含 AI 草稿与复核记录的审计视图。
5. **日志保留**：`LOG_RETENTION_DAYS=90` 已配置化并在启动时清理；具体保留规则仍待业务确认（方案 D6）。
6. **数据范围（scope）**：`user_roles.scope_type/scope_values` 列已就位但未启用，管理员当前可见全库。
