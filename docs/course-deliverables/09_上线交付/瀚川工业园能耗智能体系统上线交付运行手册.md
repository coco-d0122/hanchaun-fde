# 瀚川工业园能耗智能体系统上线交付运行手册

> 依据：仓库 main@`11d3992` 真实配置（Dockerfile、docker-compose.yml、README、scripts/）。凡未经执行验证的命令均标 **【待验证】**。本项目从未部署到正式生产环境，无正式上线地址与客户验收记录——手册描述的是"试点部署流程"，不宣称已上线。

## 1. 系统架构
模块化单体（详见第 7 项详细设计 §1）：FastAPI 单进程 + SQLite(WAL) + 内存向量索引 + 原生 JS 前端；Agent 经 app/core/llm.py 调用 LLM（支持 mock 离线与真实 API）。

## 2. 运行环境
Python 3.11+（本地 3.x 实测）；Docker 24+ / Compose v2（**本机未验证，待验证**）；内存 ≥2G；磁盘 ≥1G（含缓存与库）。

## 3. Python 依赖
`pip install -e ".[dev]"`（pyproject.toml 定义运行与 dev 分组；实测通过）。

## 4. Docker 部署 **【待验证】**
```bash
docker compose up -d --build   # 构建并后台启动
docker compose ps              # 等到 healthy
```
本机 Docker 守护进程不可用，镜像从未构建成功；首次部署须在有 Docker 的环境执行并记录结果。

## 5. 环境变量
以 `.env.example`（33 项）为准，关键项：`DB_URL`、`JWT_SECRET_FILE`、`LLM_PROVIDER`（mock/openai 兼容）、`LLM_API_KEY`、`LLM_MODEL`、`RATE_LIMIT_ENABLED/PER_MINUTE/GLOBAL_PER_MINUTE`、`LLM_DAILY_TOKEN_BUDGET`（默认 500000，0 不限）、`AGENT_ENABLED`（false=停用 Agent 保留人工功能）、`METRICS_ENABLED`。

## 6. 数据库初始化
SQLite 自动建表（应用启动时 create_all）。生产建议：`DB_URL` 指向独立目录，开启 WAL（session.py 已默认）。

## 7. 管理员初始化
```bash
python -m app.init_admin --username admin --role admin     # 交互输入密码（实测可用）
python -m app.init_admin --list                            # 列出现有用户
```

## 8. 知识库初始化
内建 6 篇制度文档位于 `knowledge/samples/`，启动自动加载建索引（缓存 `.cache/docs/`）；首次启动如需重建：`rm -rf .cache && python -m uvicorn app.main:app`（README 实测命令）。后台可上传/重处理/删除自建文档（内建文档受保护）。

## 9. 服务启动（本地/裸机，实测）
```bash
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```
访问 `http://127.0.0.1:8000/`；健康检查 `GET /api/health` 返回 kb/llm 状态。

## 10. 服务停止
裸机：Ctrl+C / 进程信号；Docker：`docker compose down` **【待验证】**。停机不影响数据（WAL 自动合并）。

## 11. 用户登录
前端登录页（/login 静态页）或 `POST /api/auth/login`（JSON：username/password）；登录颁发 HttpOnly JWT Cookie；写操作需携带 `X-Requested-With: XMLHttpRequest`（CSRF）。

## 12. Agent 使用
问答页选"异常分析"模式或指定异常事件；`POST /api/agent/analyze`（SSE 流式）。上限：12 次工具调用/同类 3 次/180s；停用时接口返回 503 中文提示。分析产出报告草稿，进入人工确认（§15）。

## 13. 数据查询
自然语言问答（知识/数据双路由）；行级范围限权用户仅见授权楼栋。演示数据：`data/samples/`（CSV 回放）。

## 14. 异常分析
`GET /api/anomalies`（状态/电表/楼栋/类型/时间过滤）→ 详情含规则结果与证据；Agent 分析产出带证据编号的草稿报告。可导出：`GET /api/agent/tasks/{task_id}/report?format=md|html`（实测可用，页眉注明待复核）。

## 15. 人工审核
- 审核点①：倍率/版本/缺失/安全/归属 5 类风险自动触发强制复核，结论暂停；
- 审核点②：草稿确认 `POST /api/agent/drafts/{id}/confirm` 或取消（保留草稿）；
- 审核点③：**签核线下执行**（复核记录只读 + 报告导出流转），系统内写入通道待开发。

## 16. 审计日志
后台审计页（/admin/audit）+ `GET /api/logs`、`/api/audit/conversations`；Agent 全链路：`/api/agent/tasks`、`/api/agent/logs`。需 `log:read` 权限。

## 17. 监控指标
`GET /api/metrics`（Prometheus 文本，log:read）：http_requests_total、5xx 计数、耗时、agent_tool_calls_total、agent_tool_failure_ratio、llm_tokens_used_today。压测实测可抓取（eval/load_test_report.json）。

## 18. LLM 预算管理
单用户日 token 超 `LLM_DAILY_TOKEN_BUDGET` 建流前 429（LLM_BUDGET_EXCEEDED）；用量入 llm_usage 表，指标端点可查当日总量。调整预算：改环境变量重启。

## 19. 备份恢复
```bash
python scripts/backup_restore_drill.py    # 实测：备份0.31s、恢复0.013s、行数一致
```
生产周期：每日在线备份（sqlite backup API）+ 每月按脚本演练；备份文件含时间戳，恢复前校验完整性（脚本内置）。

## 20. 常见故障
| 现象 | 处理 |
|---|---|
| /api/health kb.ready=false | 知识库未就绪：检查 knowledge/samples 与 .cache 权限，重建缓存 |
| 429 Too Many Requests | 限流或日预算触发：按 Retry-After 等待或调环境变量 |
| Agent 503 | AGENT_ENABLED=false：确认是否计划内停用 |
| 登录后 403 写操作 | 缺 CSRF 头：前端已自动带，自建客户端需加 X-Requested-With |
| SQLite "database is locked" | 已修复（busy_timeout=10000）；若再现检查是否有外部进程占用库文件 |

## 21. 版本回滚
代码回滚：`git checkout <tag/commit>` 后重启；数据库回滚：恢复最近备份（§19）；知识库回滚：文档版本链 + 重处理；提示词回滚：后台版本恢复（PromptTemplateVersion）。**回滚演练未实际执行，执行时须记录**。

## 22. 安全检查
上线前核对（对应阶段9清单）：密钥不入库（.env/.jwt_secret 在 gitignore）；越权抽测（跨楼栋/未登录/低权限写）应全数 401/403；pip-audit 0 高危（已实测）；AGENT_ENABLED 停用演练；审计记录抽查。

## 23. 试点验收
按第 6 项需求文档 §10 执行：技术验收（评测 30/30、越权 403、5 类强制复核、P95 指标）+ 业务验收（账实差异 <1%、定位半天内，基线待业务方书面确认；叶书参与验收；傅景对风险边界一票否决）。评价记录保留 90 天后复核归档或删除（执行人与复核人待定）。
