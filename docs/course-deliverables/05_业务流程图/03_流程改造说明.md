# 瀚川工业园能耗异常定位｜业务流程图第二版说明

## 版本与依据
版本：V2（2026-11-06）。依据：FDE合成训练资料、六角色需求发现信息及顾明岚三轮访谈。不是生产现场已验证流程。

## 主要改进
- 改造前：突出总分表差异、倍率/回路/设备归属核对、版本冲突、跨岗位等待和返工。
- 改造后：数据校验优先于异常检测；确定性规则负责数据检查，Agent负责查询、组织证据与生成草稿。
- 人工审核点①：倍率错误、版本冲突、关键资料缺失或系统不可用时暂停结论，人工核查。
- 人工审核点②：用户明确确认报告提交，不确认仅保留草稿。
- 人工审核点③：授权人员审核结论；涉及电气安全的决定由电气安全主管签核。
- 边界：不控制工业设备、不改写原始读数、不自动计费、不代替业务审批。

## 量化指标与证据缺口
- 已有业务目标：异常定位从约3天缩至半天；单位产出电耗同比上升14%，目标下降8%。目标不等于已实现。
- 约240块电表、15分钟采样、两栋楼试点、账实差异<1%：须与资料和试点验收口径核对。
- 顾明岚访谈明确缺少具体事件的时间、楼栋、电表编号及各节点耗时；因此图中不虚构具体工单数据。
