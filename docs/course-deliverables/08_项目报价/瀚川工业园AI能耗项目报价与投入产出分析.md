# 瀚川工业园 AI 能耗项目报价与投入产出分析

> 性质：**课程模拟报价**，基于仓库 MVP 复用价值测算；非真实商业合同报价。试点预算上限以访谈口径约 18 万元为参考。
> 重要的复用前提：本仓库已有可运行 MVP（约 17,000 行，pytest 74 通过、评测 30/30），报价按"在 MVP 基础上增量交付"计算，**不把已完成部分计入从零开发工作量**。

## 1. 三档功能范围

| 档位 | 范围 | 对应 MVP 状态 |
|---|---|---|
| 低配（基础版） | 部署 MVP 现有能力：问答+异常查询+规则检测+报告草稿+人工确认+审计；历史回放口径；单实例 | 复用约 90%，仅部署与培训 |
| 中配（试点版，**推荐**） | 低配 + 实时采集接入（2 栋楼 240 表）+ 15 分钟调度 + 待刷新标注 + 审核点③签核写入 + 人工修复队列 + 报表导出完善 | 新增约 6 项待开发功能 |
| 高配（扩展版） | 中配 + 交接工单状态机 + 误判周报闭环 + 统计基线检测 + PG/多实例迁移 + 全楼推广改造 | 大部分 P2 功能 |

## 2. 人天与单价假设

课程模拟单价：开发 2,000 元/人天、数据集成 2,500 元/人天、测试 1,500 元/人天、运维支持 1,200 元/人天。（真实商业报价通常为模拟值的 1.5-2.5 倍，含风险溢价与利润。）

## 3. 成本测算（人天 → 金额）

| 成本项 | 低配 | 中配 | 高配 | 说明 |
|---|---|---|---|---|
| 开发（含 SRC 增量） | 5 天 / 1.0 万 | 30 天 / 6.0 万 | 65 天 / 13.0 万 | 低配仅部署配置化；中配含采集调度、签核写入、修复队列；高配含工单流+基线模型 |
| 数据集成 | 2 天 / 0.5 万 | 8 天 / 2.0 万 | 15 天 / 3.75 万 | 接口联调、倍率/归属数据治理 |
| LLM 与知识库 | 0.5 万/年 | 1.0 万/年 | 2.0 万/年 | API 调用+知识库运营（日预算 50 万 token 封顶保护） |
| 测试 | 2 天 / 0.3 万 | 8 天 / 1.2 万 | 15 天 / 2.25 万 | MVP 已有 74 测试+30 评测，按增量计 |
| 部署 | 1 天 / 0.2 万 | 2 天 / 0.4 万 | 4 天 / 0.8 万 | 含 Docker 化验证与压测复测 |
| 培训 | 1 天 / 0.2 万 | 3 天 / 0.6 万 | 6 天 / 1.2 万 | 六角色分岗培训 |
| 运维（年） | 0.6 万 | 1.2 万 | 2.4 万 | 巡检、备份演练、告警值守 |
| **首年合计** | **约 3.3 万** | **约 12.2 万** | **约 25.4 万** | — |

低配含免费 MVP 复用价值（若从零开发同类系统约需 60-80 人天/12-16 万）；高配超出试点预算上限，建议推广期再立项。

## 4. 年度净收益与投资回收期（中配为基准）

**收益口径红线**：节能收益只计入**经人工确认、剥离产量变化、扣除维护与复核成本**的部分；系统不改变产量，产量波动带来的电耗下降不构成 AI 收益，不作结算依据。

| 收益项 | 计算（保守口径） | 年金额（估算） |
|---|---|---|
| 定位提效 | 3 天→0.5 天，异常处理人力按 0.5 人·天/次×月均 4 次×1.5 万/人月折算 | 约 2.7 万 |
| 月末核对降耗 | 4 人天→1 人天×12 月×700 元/人天 | 约 2.5 万 |
| 确认节能收益 | 电耗 -8% 目标的保守实现（按电费基数 300 万/年×1%-2% 确认口径） | 3.0-6.0 万 |
| 争议与返工减少 | 计费争议往返减少 30%（样本待核） | 约 1.0 万 |
| **年收益合计** | 保守/基准/乐观 | 5.2 / 9.2 / 12.2 万 |

**投资回收期**：中配投入 12.2 万 → 保守 28 个月 / 基准 16 个月 / 乐观 12 个月。低配 3.3 万 → 基准 5 个月。高配需以推广范围重算。

## 5. 情景分析

| 情景 | 假设 | 中配回收期 |
|---|---|---|
| 保守 | 仅定位提效+核对降耗兑现，节能确认 1% | 28 个月 |
| 基准 | 节能确认 1.5%，争议减少 30% | 16 个月 |
| 乐观 | 节能确认 2%，试点推广到 4 栋楼 | 12 个月内 |

## 6. 推荐：两栋楼试点（中配）

- 首年投入约 12.2 万，落在访谈口径 18 万预算上限内；
- 验收硬线：账实差异 <1%、定位半天内（基线口径待业务方书面确认）；
- 验收通过后再决策推广（推广按高配口径另行报价）。

## 7. 费用性质区分

1. 本表为**课程模拟报价**（教学测算）；
2. **真实商业报价**需现场勘察后重估（接口现状、历史数据质量、安全合规要求）；
3. **试点预算上限** 18 万（访谈口径，需顾明岚书面确认分配）；
4. **后续扩展成本**（推广期）：高配首年约 25.4 万 + 每年运维 2.4 万起。
