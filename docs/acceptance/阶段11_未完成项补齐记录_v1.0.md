## 3. 压测发现并修复的缺陷（D2-01 首个实测成果）

- 现象：首轮 Agent 10 并发出现 3 次 HTTP 500（错误率 1.1%），违反"5xx=0"硬性下限。
- 根因：SQLite 写锁竞争——并发工具调用写 `agent_tool_calls` 时抛
  `sqlite3.OperationalError: database is locked`（aiosqlite 默认 timeout=0，冲突立即失败）。
- 修复：`app/db/session.py` 连接层 `PRAGMA busy_timeout=10000` + `sqlite3 timeout=30`；
  修复后全部场景 5xx=0。该缺陷在单进程功能测试下不可见，只有压测能暴露。
