# 总表与分表数据核对规则

> ⚠️ **本文件为原型测试用「模拟规则」，不是瀚川工业园已确认的真实规则。**
> 文中阈值（如 3%、1.5%）为演示参数，未经现场校验，不得作为验收依据。

## 1 核对的基本原理

### 1.1 物理基础

总表计量的是某个供电范围内所有负荷的总用电量，分表计量的是该范围内各分支的用电量。理论上：

```
总表电量 = Σ（各直接分表电量）+ 线路损耗 + 变压器损耗 + 未计量负荷
```

### 1.2 为什么不会完全相等

即使计量完全准确，总表电量也会略大于分表合计，原因是：

- 线路损耗（通常 1%~3%）
- 变压器空载与负载损耗
- 分表自身的计量误差（0.5S 级表允许 ±0.5%）

因此核对的目标不是"完全相等"，而是"差异在合理范围内"。

## 2 计算口径

### 2.1 必须先转换为区间电量

**绝对不能用累计示值直接相加。** 累计示值（表底）是从装表至今的累积量，两块表的表底相加没有任何物理意义。

正确做法：

```
区间电量 = （本时点示值 − 上一时点示值）× 该区间生效倍率 × 单位折算系数
```

### 2.2 差异率定义

```
技术平衡差 = 总表电量 − Σ（直接分表电量）
技术平衡差率 = 技术平衡差 ÷ 总表电量
```

分母取总表电量，物理含义是"总表电量中有多大比例无法被分表解释"。

### 2.3 只取直接分表

计算 Σ 分表时，**只能累加该总表的直接下级分表**。若存在三级计量（总表 → 楼层表 → 设备表），把设备表也加进来会造成重复累加，差异率会严重偏大。

### 2.4 与结算差异区分

必须把两个概念分开：

| 概念 | 公式 | 用途 | 建议阈值（模拟） |
|---|---|---|---|
| 技术平衡差率 | (总表 − Σ分表) ÷ 总表 | 发现计量与接线问题 | ±3% |
| 结算差异率 | (计量电量 − 租户账单电量) ÷ 账单电量 | 财务对账 | ±1% |

**两者不得合并使用同一个"差异率"字段。**

## 3 差异方向的含义

### 3.1 总表大于分表合计（正差异）

说明有电量未被分表覆盖，常见原因：

1. 存在未装表的负荷（临时用电、私接、新增设备未及时建档）
2. 分表计量偏低（CT 二次侧接触不良、表计漂移、倍率配置偏小）
3. 线路与变压器损耗超出经验值
4. 分表在该时段存在数据缺失，缺数被直接计入差异

### 3.2 分表合计大于总表（负差异）

说明分表侧计量偏大或重复计量，常见原因：

1. 分表倍率配置偏高，同一负荷被放大计量
2. 同一回路被两块表重复计量（串表）
3. 分表覆盖了总表计量范围之外的负荷（接线越界）
4. 总表与分表的统计时段未对齐（冻结时间不同造成错位）

**负差异通常比正差异更严重**，因为它往往意味着结算数据被系统性放大，会直接引发租户争议。

## 4 核对周期与时机

| 周期 | 目的 | 说明 |
|---|---|---|
| 逐 15 分钟 | 实时发现突变 | 用于异常告警，噪声较多，需设置最小电量门槛 |
| 逐小时 | 定位异常时段 | 平衡分析的主要粒度 |
| 逐日 | 日常核对 | 与运行日志、检修记录对照 |
| 逐月 | 结算前核对 | 必须完成，结果作为对账依据 |

## 5 数据处理注意事项

### 5.1 表底回退

表底回退（本时点示值小于上一时点）通常由换表、清零、通讯补采乱序导致。处理方式：

- 该区间**不产生电量**，标记为数据质量问题
- **不参与平衡计算**——否则会凭空造出一个巨大的虚假差异
- 转人工确认是否属于换表事件

### 5.2 数据缺失

某块分表在某时段无数据时，若直接按 0 参与求和，会把缺数误判为"总表大于分表"。正确做法：

- 该时段整体标记为"数据不完整"
- 平衡校验跳过该时段，或按同期均值估算并明确标注
- 同时生成数据质量异常单

### 5.3 时点对齐

所有参与求和的分表与总表，必须使用**同一时间桶**（如整点）。不同表冻结时间不同会造成系统性错位，在负荷波动大的时段尤其明显。

## 6 差异处置流程

1. 先排除数据质量问题（缺数、回退、时点错位）
2. 再排除倍率与单位问题（逐表核对倍率与单位）
3. 再排除归属问题（是否有表挂错了父节点、是否有回路重复接入）
4. 以上都排除后，剩余的差异才可能是真实的线路损耗或未计量负荷
5. 差异原因与处理结论必须留档，作为下期核对的基线
